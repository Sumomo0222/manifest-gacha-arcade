# 霓虹游戏厅 · 祝福显化扭蛋机

一个打开就能玩的静态创意互动网页：走进夜晚的霓虹游戏厅，向主扭蛋机投入一枚「心愿币」，转动实体旋钮，看胶囊翻滚、从出蛋口滑落到托盘并自动打开，弹出一张属于今晚的祝福卡。

> 这里的「显化」只代表创意互动与情绪价值，不构成任何现实结果承诺；祝福文案是温暖的行动提示，而非算命、医疗或投资建议。

## 这个作品是什么

- 一个纯 HTML / CSS / JavaScript 的**单页静态场景**，无框架、无构建、无外部图片素材。
- 完整的三层游戏厅场景：
  - **背景**：霓虹灯牌（银河游戏厅 / 心愿扭蛋 / 显化屋 OPEN 24H…）、墙面、远处机器剪影、散景光斑；
  - **中景**：左右两侧虚化暗化的娃娃机、游戏币兑换机、迷你扭蛋机、街机；
  - **前景**：主祝福显化扭蛋机（带厚度、落地阴影、环境光晕），立于带透视与反光的地砖上。
- 所有机器、灯牌、地砖、胶囊均由 HTML / CSS 自绘。

## 如何本地打开

`dist/` 是可直接部署的纯静态目录，双击打开即可，无需本地服务：

```
manifest-gacha-arcade/dist/index.html
```

推荐用 Chrome / Safari / Edge 等现代浏览器打开（手机浏览器同样支持）。

## 有哪些交互

1. 点击底部「投入心愿币」按钮，或直接点击机器上的**投币口** → 心愿币滑入；
2. 点击机器正面的**实体圆形旋钮** → 旋钮旋转，玻璃罩内胶囊翻滚，屏幕显示「正在显化」；
3. 选中的胶囊进入机身内部通道，从**出蛋口**滑出，落到**接蛋托盘**；
4. 胶囊在托盘上**自动弹开**（无需再点击），伴随星屑迸发；
5. 祝福卡以全屏居中弹窗出现，包含：祝福名称、图标、显化提示、今日小行动、分享短句；
6. 「复制祝福」一键复制文本（浏览器限制剪贴板时，自动展开可手动全选复制的文本框）；
7. 「再抽一次」自动重新投币，再次转动旋钮即可；点弹窗空白处或按 Esc 收起卡片回到待机。

机器屏幕会实时显示状态：等待心愿币 → 已投币 → 正在显化 → 祝福已抵达。

## 如何部署

`dist/` 目录即部署产物，任意静态托管 / CDN 均可：

- **Vercel**：`vercel deploy manifest-gacha-arcade/dist --prod --yes`
- **Netlify**：控制台拖拽上传 `dist/`，或 `netlify deploy --dir=manifest-gacha-arcade/dist --prod`
- **Cloudflare Pages**：`wrangler pages deploy manifest-gacha-arcade/dist`
- **GitHub Pages**：把 `dist/` 内容推到仓库并开启 Pages
- **OSS / COS / 任意对象存储**：上传 `dist/` 内三个文件并开启静态托管

无需环境变量、无需后端。

## 继续优化的方向

- **更多祝福卡**：在 `script.js` 的 `BLESSINGS` 数组追加新条目即可（名称 / 图标 / 提示 / 小行动 / 分享短句）；
- **节日主题**：按日期切换灯牌文案与配色（圣诞、新年、生日彩蛋等）；
- **胶囊收藏册**：用 `localStorage` 记录抽过的祝福，做一枚「收集进度」徽章；
- **音效**：投币「叮」、旋钮「咔哒」、开蛋「啵」——用 Web Audio 合成，保持零素材；
- **分享卡片图**：用 Canvas 把祝福渲染成可保存的图片，方便发社交媒体；
- **桌宠模式**：待机时玻璃罩内胶囊偶尔自行滚动，增加「游戏厅还活着」的氛围；
- **无障碍增强**：为动画补齐更多 `aria-live` 描述，支持纯键盘完成完整流程。
